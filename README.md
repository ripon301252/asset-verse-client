# AssetVerse – Full Project Documentation (README)

## 📌 Project Name

**AssetVerse** – A Complete Asset Management System

---

## 🎯 Purpose of the Project

AssetVerse helps companies manage their office assets, employees, inventory, and requests in a structured way. HR/Admin/Employee roles can track asset assignments, pending requests, approvals, returns, and overall team activity.

# 🖥️ Client-Side (Frontend)

## 🔥 Features (Client)

* User Authentication (Login/Register)
* Dashboard for Employee, Manager & HR
* Asset List (Search, Filter, Sorting)
* Asset Request System
* My Assets Page (Pending / Approved / Returned statuses)
* Team Members Page
* HR Access: Approve/Reject Requests
* Image Upload (Employee & Asset)
* Dark/Light Mode
* Responsive UI
